---
title: Channels & messaging
description: Sending messages, threads, mentions, and reactions in text channels.
---

Text channels are the core of day-to-day communication on Mikoto.
This page covers what you can do inside one.

## Sending a message

Click into the composer at the bottom of any text channel, type, and
press **Enter** to send. **Shift+Enter** inserts a newline without
sending.

Messages support **Markdown** — bold, italic, lists, links, fenced
code blocks, blockquotes, and inline code all work. The composer
renders a live preview as you type.

## Mentions

Type `@` followed by a name to mention a user. Mikoto offers
autocomplete from the current space's members. Mentioned users get
a notification regardless of their per-channel settings.

You can also mention a **role** the same way (`@role-name`) if you
have permission to do so.

## Replies and threads

Hover any message and click **Reply** to send a reply inline. The
parent message is shown as a quoted block above your reply, and
both messages stay linked.

For longer side-conversations, **threads** are a separate view spun
off from a parent message. Open the thread sidebar from the same
hover menu — every reply inside the thread stays grouped together
without flooding the main channel.

## Reactions

Hover a message and click the smiley icon (or press **R**) to add an
emoji reaction. Click an existing reaction to toggle yours on or
off. Useful for lightweight acknowledgement without sending a full
message.

## Editing and deleting

You can edit or delete **your own** messages from the hover menu.
Moderators with the "manage messages" permission can also delete
others' messages.

Edited messages are marked with an "(edited)" tag. Deleted messages
disappear from the timeline entirely — there's no tombstone.

## Attachments

Drag a file into the channel, or click the **paperclip** in the
composer, to attach images, videos, audio, or arbitrary files.

- Images and short videos render inline.
- Other file types show as a download card.
- Maximum file size depends on the server's configuration; the
  hosted instance allows up to 25 MB per file.

## Direct messages

DMs work like a one-channel-deep version of a space. Open the
**Direct messages** panel in the sidebar, pick a friend, and you
get a private text channel between you. Group DMs (multiple
participants) work the same way.

You can only DM people on your [friends list](/users/friends).

## Search and history

Channels keep full message history. Use the **search** icon at the
top of any channel to find old messages — search supports plain text,
`from:@user`, and `has:link`, `has:image`, `has:file` modifiers.
