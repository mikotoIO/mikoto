Mikoto is a messaging platform for online communities. It combines
thread-based chat, voice and video, and collaborative wiki-style
documents into a single workspace called a **space**.

This site is the **end-user** guide. If you're integrating against
Mikoto from another application, see the
[Developer guide](/developers). If you're working on Mikoto's source
code, see the [Contributors guide](/contributors).

## What you get

- **Spaces** — top-level communities, similar to a Discord server or
  a Slack workspace. You can join as many as you like.
- **Channels** — the rooms inside a space. Channels come in three
  flavors: text, voice/video, and collaborative documents.
- **Direct messages** — private one-to-one or group conversations
  with people on your friends list.
- **Handles** — your human-readable identity, e.g.
  `you.mikoto.io`. No four-digit discriminators. Custom domains are
  supported.
- **Wiki documents** — long-form, real-time collaborative pages.
  Multiple people can edit a single document simultaneously.

## Where to start

- New here? Walk through [Getting started](/users/getting-started) to
  create an account and join your first space.
- Already in a space? Jump to
  [Channels & messaging](/users/messaging) to learn the basics.
- Setting up your own community? See
  [Creating a space](/users/spaces).

## Where Mikoto runs

Mikoto is open source. You can use the hosted instance at
[mikoto.io](https://mikoto.io), or self-host your own server — see
the [Contributors guide](/contributors/quickstart) for setup details.
